# Contribuer

- Périmètre du dépôt : [`SCOPE.md`](SCOPE.md). Un changement qui en sort va dans le dépôt responsable ([carte des dépôts](REPOSITORY_MAP.md)).
- Branches, titres de PR (Conventional Commits) et releases : [git-workflow](docs/git-workflow.md).
- Travailler sur plusieurs dépôts à la fois : [DEVELOPMENT_SETUP](DEVELOPMENT_SETUP.md).
- Contrat modifié (protocole, format de données, API) : version, changelog et dépôts consommateurs dans la même série de PR ([VERSIONING](VERSIONING.md)).
