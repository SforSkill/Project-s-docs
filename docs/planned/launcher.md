# Project-s-launcher (prévu, P3)

**Mission** : installer, vérifier, mettre à jour, réparer et lancer le jeu. Canaux prévus : stable, beta, experimental, development. Retour possible à une version précédente, vérification des signatures de publication.

**Aujourd'hui** : le jeu est distribué en archive Windows ou Linux. L'archive est attachée à la release GitHub, avec sa somme sha256 et le contenu épinglé, et le client se lance directement. Aucun launcher n'est imposé tant que l'archive suffit.

Le lancement direct du client restera toujours possible.
